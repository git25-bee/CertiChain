# CertiChain – Blockchain-Based Student Certificate Verification System

CertiChain is a simple web application for **issuing, storing, and verifying student certificates** using Certificate IDs and QR codes. It uses **React.js, Python Flask, Firebase Firestore, Firebase Authentication, and SHA-256 blockchain-style hashing** to provide secure and tamper-evident certificate verification.

## Features

* 🔐 Firebase Authentication
* 📜 Certificate Issuing & Management
* 🔍 Certificate ID Verification
* 📱 QR Code Verification
* 🔗 Blockchain-style Transaction History
* 🔒 SHA-256 Hashing
* ⚠️ Certificate Revocation
* ☁️ Firebase Firestore Database
* 💻 Simple Light-Themed UI

## Tech Stack

**Frontend:** React.js
**Backend:** Python + Flask
**Database:** Firebase Firestore
**Authentication:** Firebase Authentication
**Hashing:** SHA-256

## Purpose

CertiChain provides a simple and efficient solution for reducing certificate forgery and making academic certificate verification faster, easier, and more reliable.
